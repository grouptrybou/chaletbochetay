# Chalet Bochetay – Website

Static website voor Chalet Bochetay, Restaurant – Brasserie – Tearoom.

## Pagina's

| Bestand | Pagina |
|---|---|
| `bochetay/index.html` | Homepage |
| `bochetay/menu.html` | Menukaart (Canva embed) |
| `bochetay/offres.html` | Wekelijkse aanbiedingen |
| `bochetay/evenements.html` | Evenementen |

## Deployment

- **GitHub Pages**: activeer Pages op de `bochetay/` map of root
- **Plesk**: upload inhoud van `_plesk/bochetay/` naar `httpdocs/`
